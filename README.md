# ChatGPT + Obsidian

Инструкция по подключению ChatGPT к локальному Obsidian на Windows через MCP, Auth0 и ngrok.

- [Полная инструкция со скриншотами (Word)](guide.docx)
- [Текст инструкции](guide.txt)

Документ содержит пошаговую настройку, диагностику ошибок, восстановление после перезагрузки и техническое приложение с кодом. Версия: 8 октября 2026 года.

Используйте собственные значения вместо шаблонов `YOUR_*`. Не публикуйте API-ключи, токены и пароли. Подключение допускает изменение файлов хранилища; изучите раздел о границах доступа перед настройкой.
